# 业务专家快审操作说明：50 条歧义节点风险定性确认

| 项目 | 内容 |
| :--- | :--- |
| 适用对象 | 产品负责人组织业务专家（监理/工程领域） |
| 任务来源 | 回填映射后剩余 50 条无法自动推断的歧义节点 |
| 预计工作量 | 50 条 × 1 分钟 = 约 1 小时（含讨论） |
| 交付物 | `source_review_decisions.json` 人工决定文件 |

---

## 一、任务背景

研究报告正文第 4 章对 347 个采集节点中的 292 个已可明确定性（★强制/△常规）。剩余 **50 条节点**因正文只列出代表性节点、且已列节点定性混合（★/△均有），无法自动推断，需业务专家确认。

## 二、审查清单

50 条歧义节点完整清单见 `docs/04-baseline-data/backfill_ambiguous.json`。按类别分布：

| 类别 | 待审节点数 | 审查要点 |
| :--- | :--- | :--- |
| 02 模板工程 | 14 条 | 准备阶段未列节点（如滑模装置组装、爬模架体安装等） |
| 03 起重吊装 | 8 条 | 准备阶段未列节点 |
| 04 脚手架工程 | 19 条 | 准备阶段未列节点 |
| 06 暗挖工程 | 8 条 | 准备阶段未列节点 |
| 11 装配式建筑 | 1 条 | 构件堆放 |

## 三、审查口径

对每条歧义节点，请专家回答一个问题：

> **该节点的现场影像是否属于"隐蔽工程或高风险工序，必须强制采集"？**

| 判定 | 标记 | 适用情形 |
| :--- | :--- | :--- |
| **★强制** | `risk_level: "★"` | 隐蔽工程、高风险工序、不可逆工序、事故追责核心证据 |
| **△常规** | `risk_level: "△"` | 常规巡视、可重复采集、辅助性记录 |

**参考依据**：
- 同类别准备阶段已列节点的定性（如方案论证★、材料验收△）
- 研究报告第 4 章该类别的总体描述
- 住建部令第 37 号及 GB/T 50319-2013 对隐蔽/旁站工序的要求

## 四、审查流程

1. **产品负责人**将本说明 + `backfill_ambiguous.json` 发给业务专家；
2. **业务专家**逐条审查 50 条节点，按上述口径给出 ★/△ 判定；
3. **产品负责人**将审查结果填入 `docs/04-baseline-data/source_review_decisions.json`（格式见下节）；
4. **技术团队**重跑生成脚本，更新种子库。

## 五、结果回填格式

在 `source_review_decisions.json` 的 `decisions` 数组中，为每条已审节点添加：

```json
{
  "node_uid": "WDGC-A-02-SC01-03",
  "issue_type": "MISSING_RISK_LEVEL",
  "resolution_status": "CONFIRMED",
  "risk_level": "★",
  "reviewer": "专家姓名/工号",
  "reviewed_at": "2026-11-XX",
  "review_basis": "业务专家快审：该节点属于隐蔽工程/高风险工序",
  "resolution": "确认★强制采集"
}
```

**字段说明**：
- `node_uid`：从 `backfill_ambiguous.json` 中复制
- `resolution_status`：固定为 `CONFIRMED`
- `risk_level`：专家判定的 `★` 或 `△`
- `reviewer`：审查人姓名或工号
- `reviewed_at`：审查日期
- `review_basis`：判定依据（简短说明）
- `resolution`：审查结论描述

## 六、注意事项

1. **不要审已自动确认的 292 条**：那些已有正文依据，无需重复审查；
2. **如有节点应驳回**：`resolution_status` 填 `REJECTED_WITH_REASON`，`risk_level` 填 `null`，并在 `resolution` 中说明驳回原因；
3. **审查期限建议**：自收到本说明起 3 个工作日内完成；
4. **有疑问的节点**：标记为 `PENDING_REVIEW` 并注明原因，不要强行判定。
